# Azmy Ehab - Personal Portfolio Website

A single-page, responsive personal portfolio and CV website for **Azmy Ehab**, a fourth-year Management Information Systems (MIS) student and aspiring web developer.

## Project Description

This website presents my professional profile, skills and programming projects in one organized page. It uses a dark theme with an amber accent and works on desktop computers, laptops, tablets and smartphones.

## Assignment Objectives

Task 1 requires a professional personal website that presents:

1. A personal professional CV.
2. Skills.
3. Previous programming projects.
4. An attractive, organized, professional design.
5. A responsive layout for desktop and smartphones.

## Technologies Used

- **HTML5** - semantic page structure
- **CSS3** - custom styling in `css/style.css`
- **Bootstrap 5.3.3** - responsive grid and navbar, loaded from the jsDelivr CDN

The page also loads two Google Fonts (Fraunces and DM Sans). If the fonts cannot load, the site falls back to system fonts. No JavaScript of my own is used; Bootstrap's script is included only for the mobile navigation menu.

## Website Sections

1. **Navigation bar** - brand name and links to Home, About, Skills, Projects and Contact, with smooth scrolling.
2. **Hero** - profile photo, name, professional title, short introduction, and buttons for projects and contact.
3. **About** - a short introduction and a CV summary (education, focus, technical skills, interests).
4. **Skills** - HTML5, CSS3, JavaScript, Bootstrap, Git and GitHub.
5. **Projects** - five project cards, each labeled with a status (Published, No public link yet, University assignment, or In development).
6. **Contact** - clickable email, GitHub and personal website links.
7. **Footer** - developer name and copyright notice.

## Running the Website Locally

1. Download or clone the project folder.
2. Open the `Student-Portfolio` folder.
3. Double-click `index.html` to open it in a web browser.

No installation or build step is needed. An internet connection is required for Bootstrap and the fonts to load.
